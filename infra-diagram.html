Geser diagram ke samping untuk melihat seluruh arsitektur di layar kecil.

Edge Layer

  • 6 domain: 5 portal dan 1 admin.
  • Cloudflare untuk SSL, WAF, CDN, dan DDoS protection.
  • Traffic filtering sebelum request masuk ke VPS.

Proxy Layer

  • nginx sebagai reverse proxy per domain.
  • Upstream/load balancing ke service aplikasi.
  • Routing admin, portal, dan API dari satu entrypoint.

App Layer

  • 5 portal Next.js 14 dengan karakter desain berbeda.
  • Admin dashboard React + Vite + Shadcn/UI.
  • Backend API NestJS dengan REST, auth, dan RBAC.

Data Layer

  • PostgreSQL untuk users, articles, portals, dan media metadata.
  • MinIO untuk gambar, media upload, dan backup object.
  • Backup PostgreSQL dengan retensi 12 bulan.

External Service

  • AI generation service untuk membuat 5 versi artikel.
  • Monitoring health check, logs, dan uptime.
  • Endpoint utama: /api/healthz.

Alur Generate Konten

Admin menulis prompt dan mengunggah gambar melalui dashboard. Backend memanggil AI generation service, menyimpan artikel ke PostgreSQL, menyimpan media ke MinIO, lalu menerbitkan konten ke portal yang sesuai.

Alur Pembaca

Pembaca mengakses domain portal. Request melewati Cloudflare, diteruskan ke nginx, lalu diarahkan ke portal Next.js yang mengambil data artikel dari Backend API.
